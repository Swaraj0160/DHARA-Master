# DHARA
### Digital Heritage Adventure & Recreation Architecture
*Where India's stories flow.*

DHARA is an immersive, interactive digital heritage gaming and learning experience exploring the civilizational richness, architecture, philosophy, and history of ancient India.

---

## 🏛️ Features

- **Dynamic Living Board & Heritage Atlas**: Uncover and reconstruct ancient civilizational epicenters (Nalanda, Hampi, Pataliputra, Thanjavur, and Varanasi).
- **Cinematic Realm Entrances**: AAA-grade authentic visual transitions and architectural immersions into ancient eras.
- **Narrative Quests & Epigraphic Puzzles**:
  - Nalanda Mahavihara manuscript hunt & palm-leaf preservation.
  - Dwarapala philosophical debate challenges.
  - Ancient mathematical & astronomical discoveries (Pingala, Aryabhata, Brahmagupta).
- **Ancient Board Games**: Fully playable adaptations of historical Indian board games such as **Ashtapada** (the ancient precursor to chess).
- **AI Historian (Grounded Epigraphy)**: Interactive knowledge companion referenced directly against Archaeological Survey of India (ASI) memoirs, travelogues (Xuanzang), and primary classical records.
- **Classroom Mode**: Comprehensive educator dashboard with curriculum mastery tracking and heritage analytics.
- **Offline & Local Persistence**: Seamless game state management powered by Zustand with persistent local storage.

---

## 🚀 Tech Stack

- **Framework**: Next.js 16 (App Router & Turbopack)
- **UI & Styling**: Tailwind CSS, Framer Motion, Lucide Icons
- **Mapping & Visuals**: Leaflet, React-Leaflet, Canvas-based interactive cartography
- **State Management**: Zustand
- **Deployment**: Vercel

## 🛠️ Getting Started

### Prerequisites
- Node.js 18.x or later
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/HereIsKrishna/DHARA.git
cd DHARA

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore DHARA.

### Production Build

```bash
npm run build
npm run start
```
